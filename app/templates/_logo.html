{# Kaagaz — the brand mark. A third layer, alongside _icons.html (functional outlined glyphs) and _bubble.html (illustrated characters). The mark is filled and shaded, so it cannot live in the icon set: that set is asserted to be fully outlined at a single 1.75 stroke weight, and a regulatory glyph has to be unambiguous at 16px. Mixing the three styles in one place is what makes an interface read as assembled rather than designed. Two variants, because the masthead and the page ground need opposite treatment: logo_mark() — for dark grounds (the indigo masthead) logo_mark_light() — for the cream page The silhouette does the work at small sizes: one sheet, one bold check, and a SINGLE heavy rule. Two thin rules were tried first and were mush at the 30px this mark actually renders at in the masthead — they turned into a grey smudge. One rule at 2.4 units survives. The app/static/favicon.svg file is the same mark on the 32px grid; keep the two in step. #} {% macro _mark(size, uid, plate, plate_edge, sheet, fold, rule, badge, check, cls='') -%} {%- endmacro %} {# For dark grounds. The plate is a lifted glass panel rather than solid indigo, so the mark has a silhouette against the masthead instead of dissolving into it, and the check is a brighter green to hold its contrast on a dark field. #} {% macro logo_mark(size=30, cls='') -%} {{ _mark(size, 'kD', ['#3A5F92', '#22406A'], 'rgba(255,255,255,0.30)', '#FFFCF5', '#E4D7BE', '#AEB7C2', '#3FA772', '#FFFFFF', cls) }} {%- endmacro %} {# For the cream page ground. Solid indigo plate, matching the favicon. #} {% macro logo_mark_light(size=30, cls='') -%} {{ _mark(size, 'kL', ['#2A4C7C', '#1B3455'], 'rgba(27,52,85,0.60)', '#FFFCF5', '#E7DAC2', '#AEB7C2', '#2F7A52', '#FFFFFF', cls) }} {%- endmacro %} {# Full lockup: mark plus the wordmark, for anywhere the two sit together. The word is set in the app's serif, so the lockup stays in the same voice as the headings rather than introducing a second typeface for the brand. #} {% macro logo_lockup(size=28, variant='dark') -%} {% set mark = logo_mark_light(size) if variant == 'light' else logo_mark(size) %} {{ mark }} Kaagaz {%- endmacro %}
